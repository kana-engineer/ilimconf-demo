# IlimConf v7 — демоверсия с двумя ролями

React + Tailwind CSS (Vite). Интерфейс на кыргызском языке.

## Запуск

```bash
npm install
npm run dev
```

## Сценарий демонстрации

1. Главная страница и информация о конференции.
2. «2 ролду көрүү» — выберите «Колдонуучу»: статьи и статусы.
3. Выберите «Администратор»: список заявок, поиск, изменение статуса, экспорт CSV.
4. «Макала тапшыруу» — демонстрационная форма загрузки Word.

Настоящей авторизации и серверного хранения данных нет. Сведения о конференции и участниках демонстрационные. Состояния сбрасываются после перезагрузки.
